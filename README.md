# 青野 · 自然生态观测

修仙世界模拟与连续横版游戏原型。仓库包含源码、美术素材、参考图片、设计文档、测试与验证记录。

| 入口 | 内容 |
| --- | --- |
| `/` | 自然灵气生态与地图观测 |
| `/feasibility/` | 横陆演化可行性实验 |
| `/sideview/` | 分层山域、桥路、洞穴与御器行旅 |

美术文件与 SHA-256 校验清单见 [资产索引](ASSETS.md)。独立资产压缩包放在仓库 Releases 中。图中参考素材的收录不表示取得独占版权或额外授权，仓库尚未指定统一开源许可。

本地浏览器原型。当前是持续开发中的基础版，完整验收依据 [08](docs/08-browser-prototype-acceptance.md)，不代表所有规则或场景已通过。

## 启动

需要 Node.js 20 或更高版本，无第三方运行依赖。

```sh
npm start
```

打开 http://127.0.0.1:4173 。资源、字体选择和模拟均在本地，不依赖 AI。

## 操作

- 地图：拖动平移、滚轮缩放，点击查看格子；F 全图。
- 顶栏：运行／暂停（空格）、单步 0.25 年、调速；新地图调整种子、规模、气候与起点。
- 左侧图层可收起。右侧检查面板按需出现，显示状态、最近一步收支、局部编辑。
- 存档导出 JSON，载入恢复；请在开发中更新前保存有价值的实验。版本变化可能需要迁移。
- 移除植物与使植物死亡不同：死亡保留遗骸，实验移除从世界输出资源。
- 帮助 → 运行诊断可暂时关闭地图绘制，世界时钟照常运行；恢复绘制后显示最新状态，用于观察独立性对照。

## 检查

```sh
npm test
npm run verify
# 标准地图优化前后对照：100 年，完整状态校验
node scripts/benchmark-speed.mjs 400
```

自动测试结果只覆盖实际列出的断言，不代表 08 全体验或性能通过。11 类场景的当前结果见 evidence/scenarios-report.md，对照初始存档位于 evidence/scenarios/，可通过界面“载入”打开。完整进度见 docs/10-acceptance-status.md，长期测量与浏览器验收仍在补齐。

## 结构

`src/world.js`：独立模拟；`src/species.js`：物种参数；`src/worker.js`：后台时钟；`src/map.js`：地图；`src/app.js`：观察与编辑；`tests/`：规则测试；`evidence/`：后续验收证据。

## 连续侧视行旅原型（2026-09-19）

启动服务器后访问 [行旅原型](http://127.0.0.1:4173/sideview/)。A/D 行走、空格跳跃、W/S 爬梯或升降、F 御器、E 建筑交互、M 行旅地图、O 世界记录。能力选择与观察定位属于试验功能。

独立的连续空间切片；旧生态实验保持在 `/feasibility/`。两者尚未共用权威存档。见 [当前项目定义及验收](docs/17-continuous-sideview-world.md)。运行 `node --test tests/sideview.test.mjs` 验证通行、飞行、区块持久化和离屏演化。

山域里按 V 切换全景／近景，W/S 沿石阶上下，E 进入洞穴。美术、尺度与前景规则见 [18](docs/18-mountain-art-and-immersion.md)。当前是试作，不代表完整游戏或全部世界规则已实现。
