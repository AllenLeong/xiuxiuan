# 灵气生态与生命规则 · 第一版设定草案

## 最新优先规则：聚气驱动与成规模区域

用户已纠正：灵气横向输送主要由目的地的聚气／吸收能力驱动，地形限制通达，不采用“库存高自动向库存低流动”作为基本规则。具备聚气能力且未达容量上限的地点可以从更贫灵地点取用；无聚气能力的空地不因低库存自动吸引灵气。效率、容量与当前充盈分别表达，环境聚集与植物体内吸收分账。现已采用独立的地下／地表聚气效率、未满比例与植物吸收需求求吸引场；作用沿实际连通结构衰减，逐边共享供给并扣账。地下和地表聚气分别设置，不能因泉口地下能汇聚，就假定地表也把所有灵气锁在原处。当前公式及工程阈值见 12，仍须随机世界长期校准。

玩家层面的林区、灵地、通道及古树影响区，须在连续范围、显著强度和持续性达到规模后识别标画；区域标签不反向赋予能力。接入方案见 [12 成规模区域](./12-regions-and-influence.md)。

## 当前讨论范围【已确定】

先讨论没有修仙法门介入时的自然世界：天地输入、大地加工、自然流动、灵物形成、生态循环，以及生命诞生、存续和死亡。

活体夺取、转移延寿、突破、施法、炼丹和阵法留到法门阶段。文中相关内容保留为后续议题，不作为当前自然规则的前提，也不要求现在决定是否存在。天然灵物自身的吸收和转化能力仍属于自然生态。

## 0. 基础描述

日月星辰提供天道之气，大地将其加工为适合生命吸收的地道之气；灵植／灵草能自然吸收、加工天道之气，普通植物不能；其中一些天生灵植加工效率高，能够使当地逐渐富集灵气。生灵参与灵气的储存、转化与流转，同时依靠有限的先天一气维持生命。修仙，是研究如何利用外部灵气改变自身、延续生命的过程。

## 1. 天地人三气

“天地人”表示灵气与天地、生灵的关系，其中“人”泛指生命，包括动物、植物和人类。

### 1.1 基础定义【已确定】

| 类别 | 定义 | 限制 |
| --- | --- | --- |
| 天道之气 | 来自日月星辰，是一切灵气的根本来源，最纯 | 灵植／灵草可以吸收、加工，普通植物不能；部分天生灵植加工效率高；其他生命的具体能力另行定义 |
| 地道之气 | 大地吸收天道之气，经地表、地下和地心环境加工后缓慢释放 | 生成、转化、储存与释放都有速率限制 |
| 先天一气 | 天道在生命诞生时赋予的一份，是每个生灵都有的生命根本 | 随生命消耗，死亡时耗尽，不作为遗留资源回流 |

所有生灵都有先天一气，但不是所有生灵都能主动修炼。吸收、储存和主动运用外界灵气的能力可以不同。

### 1.2 记录方式【建议】

分别记录来源、加工性质和当前位置。后天积累的灵气进入生命体后，不会仅因位置变化就成为先天一气。

先天一气和后天灵气分账。上述三者并非三个完全同层的分类轴，术语与数据分类的具体关系待明确。

## 2. 灵气生成与地域差异【草案规则】

大地加工路径：日月星辰输入 → 大地吸收 → 地质环境转化 → 地下储存与输送 → 向环境释放。

灵植加工路径【已确定】：日月星辰输入 → 灵植／灵草吸收并加工天道之气 → 后天灵气积累与生态流转。普通植物没有这项能力，不能仅靠时间累积就默认加工天道之气；这与普通人无法聚气的区分相对应。

### 灵地与灵植的双向关系【已确定】

- **灵地滋养灵草：**灵气聚集的地方会有灵草。具体出现条件、时间，以及是否由普通植物转变而来，尚未确定。
- **灵植形成灵地：**也有一些天生灵植／灵草，具有较高的天道之气加工效率，能够使某个地方逐渐成为灵气富集地。其来源是天道输入，不是凭空生成灵气。

两种路径可以并存，不要求所有灵草都必须先依赖已有灵地。植物自然生长达到灵性层次可用“植物修仙”作直觉比喻，但不据此引入有意识修炼或法门规则。

此前“所有植物都能低效加工天道之气”的 v0.3 表述已被本次规则替代。加工需要时间，但不再把所有灵草的效率一概规定为低。灵植加工所得的命名、物种间效率与大地加工效率的定量比较尚未确定。加工产物进入环境的自然路径见第 4 节；释放比例和速率尚未确定。

天道之气可长期持续供给，因此灵气总体可再生；地方的可用产出仍受当地条件约束。

| 特征 | 含义 |
| --- | --- |
| 接收条件 | 能接收多少天道之气 |
| 吸收能力 | 有多少输入被大地接纳 |
| 转化效率 | 多快转化成地道之气；数值实现需另分单位时间处理量与转化比例 |
| 储存容量 | 地层和物质能容纳多少 |
| 传导能力 | 与其他地区交换灵气的能力 |
| 释放速度 | 储量多快转为环境中可用的灵气 |

储量大、产量高和地表浓度高，是三件不同的事。

### 2.1 属性的环境成因

同源天道之气经过不同环境加工，可以形成不同性质的地道之气。以下为待细化实例：

- 地火环境赋予活跃、猛烈的性质。
- 寒冷地层赋予稳定、缓慢释放的性质。
- 特定矿物改变灵气与物质结合的方式。
- 水系参与输送，并使沿途发生进一步交换。

属性必须有环境成因，不能只按州名分配。纯度、属性、吸收难度分别表达；最纯不代表最容易吸收，地道之气可能更适合特定生命。

### 2.2 灵脉

灵脉是连续的地质结构，包含生成、输送、蓄积和释放环节。它可以跨州；截流、开采和地质变化可能影响其他地点。州界本身不改变灵气流动。

### 2.3 地下出气后的去向【已确定方向】

地下释放只是灵气从地下进入地表环境。此后除当地吸收、载体储存与宇宙逸散外，还存在横向输送，不能默认向周围均匀摊开。

- 发送地的出口与接收地的入口共同限制流入；到达后，由目的地的各方向通路、载体结合与储存能力、植物吸收共同决定后续去向。
- 目的地可以继续输送、向多个方向分流、逐渐留存，或由植物截留；这些是结构与收支形成的结果，不预先给每格指定“通道／灵地”标签。
- 后续输送逐段发生，不能从源头预选最终目的地后直接转移；中途吸收与逸散会减少最终到达量。
- 地理固定意味着传导结构稳定，不要求实际流向、流量永久固定。源头强弱、接收地库存和植物竞争改变时，实际流动可以变化。

因此“流经很多”不等于“当地存得多”，“植物积累很多”也不等于“地表游离浓度高”。具体驱动力、速率和地理到通达性的映射属于待验证的模拟实现，详见 [灵气输送与通道逻辑](./11-qi-transport.md)。

## 3. 灵气如何量变为质变【建议原则】

灵气在合适的物质结构、浓度和持续时间下，会改变其结合方式，形成新的性质或承载能力。

- 岩层长期蓄积灵气，在特定条件下形成灵性矿物。
- 生物长期接触灵气，部分个体形成可承载灵气的组织。
- 灵性组织继续积累可能超出承载上限并受损。

达到数量门槛不保证转变成功；不同环境产生不同结果；过高浓度可能有害；灵物形成需要时间与条件。灵物应是长期作用的产物，而非无来源定时刷新。

## 4. 生态流转与留存

### 4.1 灵植向环境输送灵气【已确定】

灵植在活着、生长时，会将部分加工后的灵气缓慢释放到周围环境；它可以同时积累自身并滋养周围，不必等到凋落或死亡后才影响环境。这是自然过程，不需要法门介入。

与已有生态流转规则衔接，存在三条路径：

| 路径 | 过程 |
| --- | --- |
| 活体释放 | 生长中的灵植缓慢释放部分加工后的灵气到周围 |
| 凋落与分解 | 落叶、落果、枯根及遗骸将后天积累带入土壤、水体与分解过程 |
| 当地摄食与归还 | 摄食、排泄及死亡只参与当地生态循环，不模拟动物跨地点搬运灵气 |

范围修正【已确定】：去掉动物跨地点搬运灵气的机制；不因此删除动物本身及当地摄食、排泄、分解过程。

上述流转的是后天灵气，不能记作先天一气释放。释放比例、速率及其与生长阶段的关系尚未确定，不默认只有储满后才释放。

**生态推论：**加工天道之气 → 活体释放与凋落积累 → 当地灵气增加 → 更适合其他灵草生长。富集能否持续、范围能否扩大，取决于输入、当地留存与向外流动，不能仅由存在一株灵植就保证整片区域持续富集。

### 4.2 循环与留存【草案规则】

主要路径：环境灵气 → 灵植 → 食草灵兽 → 捕食者 → 排泄物与遗骸 → 分解者、土壤和水体 → 再次吸收。

两种留存方式：

- **静态储存：**长期结合在矿物、木材、骨骼等物质中。
- **动态留存：**反复在当地生命与环境之间转移，延长停留时间。

森林的游离灵气浓度可以不高，而树木、动物、菌类和土壤中的总量很大。生态丰富程度还需考虑总留存量、循环速度、转移损耗、关键生物存续，以及外界补充和向外输出。

生态同时包含两种不同作用：灵植／灵草吸收、加工天道之气，为生态引入外部灵气；生物与环境之间的反复转移，提高保存和重复利用效率。两者分别计算，生态不会凭空增殖灵气。普通植物不具有加工天道之气的能力；部分天生灵植加工效率高，可逐渐改变当地灵气环境。

**已确定补充：未被吸收或储存的游离灵气，会逐渐逸散到宇宙。**

- 首版将地表游离库视为暴露于宇宙的部分；地下储存、生命体内、土壤、矿物和遗留物中的结合库存不直接逸散，释放回游离环境后才参与逸散。
- 逸散是持续的外部输出，有明确去向与收支记录，不是一瞬间清空，也不是内部转移。
- 输入与生态结构相对稳定时，输入、吸收、释放、储存和逸散可形成动态平衡；源头与生态发生变化，平衡随之改变。并不保证每一格每个时刻都恒定。
- 具体速率属于可调模拟参数，尚未确定为世界观常数。

## 5. 普通生灵、灵物与先天一气

### 5.1 所有生命都有先天一气【已确定】

先天一气与整个生命的存续相关，不能通过反复摘叶、剪毛、取血无限获取。普通植物的一片叶子，不因来自活物就提供整株植物的先天一气。

### 5.2 灵物积累后天灵气【草案规则】

灵草、灵树、灵兽具有更强的吸收、承载或转化能力。

- 灵树叶片、灵果、灵兽组织等可作为后天灵气载体。
- 部位不同，含量、性质和可利用程度不同。
- 采摘和捕猎把当地生态中的灵气带走。
- 吸收、加工天道之气是灵植／灵草的能力，普通植物不具备。部分天生灵植加工效率较高；具体效率、承载与转化差异留待细化。
- 普通植物不能加工天道之气，不等于已经决定其不能受环境灵气影响；它是否、如何转变为灵草仍待讨论。

### 5.3 自然摄食与吸收【草案规则】

自然摄食只能利用材料中部分后天灵气，受材料含量、消化提取、身体适配和吸收能力限制。

具体比例与单位时间吸收上限尚未确定。摄入过量可超过承载能力并造成损伤。此前“材料含量 × 提取效率 × 身体适配程度 × 吸收与炼化能力”的概念式，以及炼丹、加工、功法对这些环节的改变，保留到后续法门阶段讨论。

## 6. 死亡、先天一气与寿命

### 6.1 生命存续与死亡【已确定】

先天一气依附于完整的生命联系；生命不可逆崩解时，剩余部分随之耗散，不成为可采集资源。

- 自然寿终：先天一气在生命存续中逐渐耗尽，生命终结。
- 致命损伤：完整的生命联系不可逆崩解，尚余的先天一气随之耗散。
- 遗骸仍可残留后天积累的灵气，进入生态分解；不得将耗散的先天一气记入这部分可回收资源。

因此，死亡后不存在等待采集的先天一气。这里明确的是其不再可采集，不额外定义耗散后的宇宙学归宿。

### 6.2 夺取先天一气【后续法门议题，当前不讨论】

草案提及此前“夺去生命才能取得先天一气”的想法，需要与死亡规则统一。

若保留，建议只允许在生命尚存时提取，直接消耗目标先天一气；耗尽导致死亡，不能死后补做提取。是否能被接收者利用、是否增加寿命、代价与效率均未确定。不能视为普通摄食固有能力。

### 6.3 修仙延寿【后续法门建议，未定案】

- 活着持续消耗先天一气。
- 肉身与生命结构决定消耗速度。
- 后天灵气用于修复、维持和改造生命结构。
- 突破提高生命运行效率，从而降低先天一气消耗。
- 单纯吸入更多灵气，不直接等量增加寿命。

此方案可以解释突破延寿，但并未确定消耗下限、延寿丹机制或境界寿命表。是否可补充先天一气、是否存在真正长生，保留为高层待定规则。

## 7. 天然灵地【草案规则】

| 类型 | 富集原因 | 脆弱点 |
| --- | --- | --- |
| 生产型 | 当地转化、释放能力强 | 来源或地质条件变化 |
| 灵植源型 | 天生高效灵植加工天道之气，使当地富集 | 依赖相关灵植存续，具体衰退过程待定 |
| 汇流型 | 接收其他地区输送的灵气 | 截流或通道破坏 |
| 积累型 | 长期形成巨大存量 | 开采远快于补充 |
| 生态型 | 生命网络降低流失、反复利用 | 关键物种、水土和循环被破坏 |

同一地点可兼具多种特征。

### 后续人为经营与法门介入【暂存，不属于当前自然规则讨论】

人为经营可影响：

- 聚灵阵改变流向。
- 储灵设施提高储存能力。
- 灵植园改善生物转化与留存。
- 地质工程调整输送和释放。
- 生态保护降低流失。
- 开采、采药与猎杀向外输出积累。

人为繁荣必须有来源和维护成本。依靠输入维持的仙山会在贸易或设施中断后衰退。

## 8. 对后续世界演化的支撑【远期设计推论，非当前法门规则】

- 修炼地点有承载限制，推动定居与争夺。
- 属性、材料和生物的地域差异推动交换与专业分工。
- 自然积累缓慢，使长期经营和保护有价值。
- 功法改善利用效率，使知识与传承成为资源。
- 开采带来即时收益，也可能破坏长期供给。
- 寿命有限，使人物在等待、研究、合作与冒险间取舍。

这些条件不直接决定谁崛起；仍需人物、知识与组织行为规则。

## 9. 第一版必须守住的约束【草案底线】

1. 所有灵气有来源，包括新生命获得的先天一气。
2. 内部转移不是消失，草到兽、遗骸到土壤均记为转移。
3. 储量与产能分开。
4. 吸收、转化、释放有速率限制。
5. 物质和生命有承载上限。
6. 先天一气与后天灵气分别记录。
7. 死亡不生成可回收的先天一气。
8. 地理连接决定流动，行政边界不自动形成阻隔。

根本矛盾：天道持续供给，但可利用灵气受空间、时间、技术和生态限制；生命能够积累力量，却无法无限等待。

## 后续地图讨论对植物能力的澄清（2026-09-16）【已确定】

普通植物不能加工天道之气；具有该能力的灵植可以加工，但不能反过来要求所有灵植都有加工能力。用户明确补充：适应恶劣环境、可直接吸收当地所产地道灵气的植物，也能成长为古树并改变地表生态，即使它不能加工天道之气。

因此天道加工能力、地道吸收能力与成长为古树分别表达。古树不是天道加工能力的同义词。具体根系取用和生态改造机制仍待细化，不因地热例子立即引入灵气属性体系。

## 植被与地表小环境（2026-09-16）【已确定方向】

植物可以逐渐改变局部温度和水分，例如遮阴降温、地表保湿，使原本不适合部分植物生长的地点变得适合。背景气候与地热条件保持存在，改变的是局部地表环境。影响速度、强度和范围尚未确定。

## 后续确认：吸收竞争与局部平衡

- 灵气充足、吸收能力强且具备合适生命结构的灵植，可持续积累并发生进一步质变；不是全部留在地表。
- 实际吸收同时受环境可用量、个体吸收能力、适配与剩余承载限制。强植取得资源会减少其他植物能取得的资源，不能各自读取同一份库存重复吸收。
- 地表游离量由输入、植物吸收和释放、结合、流动与宇宙逸散共同决定。灵植存在不等于此处地表浓度高，更不自动称为灵地。
- 不设定全图应该有固定数量或比例的灵地；需验证模型是否自然形成局部富集、贫乏和竞争。
