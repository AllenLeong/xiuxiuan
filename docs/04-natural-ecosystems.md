# 自然灵气生态的可能形态

版本：v0.2。用户认可这些形态作为可能结果，并明确去掉动物搬运机制。形态不作为生成器输入或预设类别；具体成因参数仍是推演，原子模拟见第五份文档。

## 边界与方法

当前仅讨论无修仙法门介入的自然环境，包括没有生物的灵气环境。普通植物不能加工天道之气；灵植可以，部分天生灵植效率高；灵植活体释放部分加工后的后天灵气，凋落、摄食和分解参与转移。先天一气不进入遗骸可回收量。

动物自身是否能直接加工天道之气、普通动植物如何成为灵物、具体耐受范围和繁殖规则尚未确定。以下摄食积累主要以具备相应能力的灵兽为例，不默认普通动物都能炼化，也不默认所有动物在所有环境均能生存。

观察一个地方时，分别追踪：外部输入、当地加工、流入流出、非生物储存、生命储存与转移、可利用浓度、承载与适配条件。既有地道流入不是本地产出，当地生物转移也不是新生灵气。

## 候选形态

| 形态 | 地理与灵气路径 | 生命参与 | 可能结果与变化 |
| --- | --- | --- | --- |
| 无生物蓄积地 | 深层岩隙或封闭地层加工并储存灵气，释放慢 | 可以没有生物 | 地下库存高而地表浓度低；若满足灵性矿物形成条件，可长期固存。通道改变后才可能向其他区域释放 |
| 无生物流通带 | 岩层裂隙或地下水通道承担输送，留存弱 | 可以没有生物 | 流经量大但本地库存不高；下游富集地可能依赖这条不显眼的通道 |
| 灵气强而生命稀少的地带 | 地火区等持续加工释放，但环境本身严酷，或浓度超出生命耐受 | 无生物或少量适配生命 | 灵气足不保证生物繁盛；不预先确定有哪些耐受物种 |
| 地养灵草的谷地 | 地层释放或多条通道汇入，地理条件利于留存 | 灵草生长、释放，适配的摄食者参与循环 | 地质输入和生态循环共同富集；灵草具体出现方式待定，不默认所有普通植物自动转化 |
| 灵植形成的局部富集地 | 原有地质供给弱，存在天生高效灵植，为当地增加天道输入 | 灵植自身释放与凋落滋养周边，可能逐渐适合其他灵草 | 可形成以灵植为中心的富集范围；核心灵植死亡后输入减少，但已有后天库存不会立即消失 |
| 高库存、低游离浓度的林地 | 地理条件与生命网络使灵气长期留存 | 灵植、组织残留、土壤与分解过程承载大量后天灵气 | 空气浓度不高仍可能总库存丰富；扰动后的释放速度取决于分解和流失，不能直接假定瞬时释放 |
| 水系连接的上下游生态 | 上游输入，经水系交换与输送，低流速或适合留存处可能蓄积 | 沿岸灵植、适配水生生命与当地有机残留参与循环 | 上游流出成为下游输入；灵气是否跟随泥沙或溶于水的具体性质待定，不能默认所有河口都富集 |
| 输入脉冲型生态 | 若天道接收或水系输送有季节变化，则输入随时段变化 | 生长与活动可能响应可用灵气变化 | 可推演生长窗口和迁徙，但季节输入规律、休眠及繁殖响应均属待定扩展 |

## 组合而非固定分区

以上是不同过程占主导的形态，不是互斥地块类别。一座山可同时有地下蓄积层、裂隙流通带、山腰灵植富集点、河谷生态。它们可以跨州连续连接。

地质供给弱不等于完全无灵气；无生物不等于无加工或无储存；有灵气不等于适合所有生命；总量高不等于游离浓度高；通量高不等于留存高。

## 可用于后续推演的连续区域例子

山腹蓄积与输送 → 谷地释放和灵草生长 → 林地留存 → 河流向外输送 → 下游适配地点积累。

另一条输入来自山坡的天生高效灵树；动物仅参与所在地的摄食与归还，不模拟跨地点搬运。每一环都能单独不存在，不应强制生成完整套装。

## 下一层需要定义的自然规则

- 属性与浓度如何影响不同生命的适配、生长和承载。
- 灵草出现、繁衍与普通植物变化的条件。
- 动物在当地摄食后的吸收、留存与排出，不跟踪搬运路线。
- 水体、地层与生物组织之间如何交换、释放灵气。

这些问题用于细化生态，不要求现在设计修仙法门或指定州产业。
