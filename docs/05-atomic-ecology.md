# 自然生态的原子模拟草案

版本：v0.1。状态：助手提出的实现建议，尚未得到逐项确认，未编写或运行模拟程序。

已定边界：生态形态是结果；行政边界不截断流动；普通植物不能加工天道之气，灵植可以；灵植活体释放；先天一气单独记账；不模拟动物跨地点搬运。仍先讨论无修仙法门的自然世界。

## 1. 原子是局部状态与转移，不是逐个微粒

把连续地理离散为相连的小地块。每块采用同一套状态和更新规则，不携带“灵谷”“仙山”“灵气荒漠”等用于驱动计算的生态标签。格网或不规则网格均可，实际尺度待选。州界只是叠加信息。

每个地块包含：

- 地理基础参数：温度、水分、岩性、地层厚度、光照／天道接收条件等。哪些参数影响加工与属性需进一步决定，不能当作已定公式。
- 由地理推导的系数：加工吞吐、转化比例、各层容量、释放和传导能力。不要为每种目标生态单独手填一组结果参数。
- 当前库存：未加工的天道输入、地下可流动灵气、当地环境可流动灵气、矿物结合量、植物后天积累、动物后天积累、凋落／遗骸量。
- 当地生命：普通植物、灵植、适配动物的种群或年龄组；生物量、健康、生长潜力、寿命／先天余量分布。

普通食物、水分等生计条件不能由灵气一个数完全取代。首版可用简化的环境供养上限，不必建立完整碳氮循环。年龄组避免一个平均先天余量使整个种群同日死亡；特殊灵树可用单体表示，是否采用待定。

## 2. 空间连接是边

地下地块之间记录传导系数；地表之间记录环境交换；水系可具有方向。传导不跨行政边界额外打折。

候选交换规则：势差 × 传导能力 × 时间步长，受源可用库存、通道上限与目标容量约束。势可先由填充程度或浓度近似，具体关系待定。多个邻居共享源库存，必须统一分配，不能每条边都独立取走全部库存。

天道为边界输入。大地与灵植的接收都从明确的输入额度分配，避免同一份输入被记两次；未接收部分保持未接收，不强制转成当地地道之气。是否共享世界级额度仍需世界规则决定。

## 3. 最小局部操作

| 操作 | 输入 → 输出 | 约束／状态 |
| --- | --- | --- |
| 接收与加工 | 天道输入 → 地下库存或灵植后天库存 | 只允许大地和有能力的灵植加工；受接收量、吞吐、转化比例与余量空间限制 |
| 地质交换 | 地下库存 ↔ 环境库存；相邻地点之间交换 | 流向与速率由连接、局部状态决定，不能按生态标签决定 |
| 结合／释放 | 可流动库存 ↔ 矿物结合量 | 需材料、结构和持续条件；灵矿形成具体机制仍为建议 |
| 灵植吸收与释放 | 环境 → 灵植；灵植 → 当地环境 | 环境吸收能力与天道加工能力分别记录；释放已定，具体速率待定 |
| 当地摄食与排出 | 植物／猎物 → 动物／当地遗留物 | 灵气按被摄食部分转移，不因动物增重另增库存；不模拟跨地搬运 |
| 凋落、死亡与分解 | 生物后天库存 → 遗留物 → 当地环境 | 分解有速率；先天一气在死亡时耗尽或耗散，不进入该链 |
| 生长、繁殖与衰亡 | 修改生物量、年龄组与容量 | 由环境适配、食物水分、可用灵气和生命状态驱动，不能直接给新生个体满额后天库存 |

生长造成容量增加不代表库存增加。加工失败的份额去向未定，不能自动作为不可回收消耗。分解者可先合并为当地分解速率，不必再逐个模拟微生物。

## 4. 一步更新的建议流程

1. 读取该步初始地理、库存和生命状态，计算天道输入。
2. 从同一状态计算加工、交换、吸收、释放、摄食及分解的请求量。
3. 对共享库存与目标空间统一限流，得到真正发生的转移；统一提交，避免遍历顺序改变结果。
4. 按实际获得的资源更新生长、健康、年龄与死亡。死亡把后天库存转入遗留物，同时按已定规则终结先天一气。
5. 记录库存变化与原因；查看总账。新出生生命获得的先天输入单独记录。

可以采用明确的分阶段同步更新替代一次统一求解，但每个阶段必须明确哪些新产物可在本步使用。时间步长需匹配最快过程；不能以无限截断代替数值稳定性检查。

## 5. 结果如何自然出现

- 同样加工量，容量大而释放慢：地下蓄积。
- 连接强、停留短：通量大，库存未必大。
- 释放足、生命环境适配：灵植有条件生长。
- 地质供给弱但存在高效天生灵植：植物输入与释放可能形成局部富集。
- 生物结合和当地循环较强：生命库存高，游离浓度可能低。
- 环境不适配：即使灵气多，也可能无生物。

这些是条件推论，不是写死的结果或已验证稳定态；多种因素组合决定实际变化。

## 6. 初始化与暂未闭合之处

初始化需要地理、初始库存和初始生命来源。不能以“达到浓度阈值就每年刷灵草”填补生命起源。

首个验证模型可使用明示的灵植种子／少量初始种群（建议），只验证其生长与环境反馈；天生灵植如何产生、普通植物如何转变、种子传播与遗传机制尚未确定。跨地种子传播亦不因此默认实现，更不重新引入动物搬运。

初次验证可先使用同类灵气；属性维度之后接入库存和适配关系（建议），不表示取消世界观中的属性。地理形成史可在此之前生成，没必要每步从造山运动算起。

下一步最需要用户定的自然规则：灵植的出现与繁殖，以及生命对浓度与属性的适配。池、边和时间步只是承载这些规则的实现建议，不能代替世界规则。

## 7. 设计层级修正：先确定因果维度，再选择计算实现

2026-09-16 用户澄清：自然生态形态只作为可能性参考，不是模拟目的、生成目标或预设分类。它们应当是底层条件和规则运行后的自然结果。前述地块、库存、时间步是实现载体，不能替代对基础维度的定义。

这里“必然结果”表示：在相应条件成立时，结果由机制推出，而非额外指定；不表示每张地图都必须出现全部形态，也不要求生态停止变化或随机历史只有一个结局。

以下为待讨论的因果维度建议：

| 基础维度 | 描述的差异 | 影响的过程 |
| --- | --- | --- |
| 天道接收 | 局部输入强度、暴露条件、时间变化 | 可用于加工的外部供给 |
| 物质加工 | 岩土或灵植能否加工、吞吐和转化比例 | 天道输入转成可利用灵气的速度 |
| 物质承载与亲和 | 材料可结合多少、结合强弱、解离快慢 | 灵气停留在哪里，如何在结合态与游离态之间转换 |
| 空间通达 | 连接方向、通道阻力、交换能力 | 灵气如何在位置和载体之间流动 |
| 加工性质 | 不同环境造成的灵气性质 | 与材料和生命的相互作用、适配 |
| 生命适配 | 物种对温度、水分、食物、灵气浓度与性质的需求和耐受 | 是否存活、能否生长以及生长速度 |
| 生命能力与生命周期 | 吸收、加工、结合、释放、繁殖、凋落、死亡和分解特征 | 生命如何改变灵气分布，以及影响能持续多久 |

这些不一定是七个标量，而是七类局部性质。浓度、库存、生物量和生态形态是随时间变化的状态或观察结果，不应与基础性质混为一谈。

地理提供材料、空间连接和生存条件；植物、动物提供不同的材料结构与生命能力。普通植物天道加工能力为零；灵植具有该能力，天生高效灵植更强。动物仅参与当地循环，其天道加工能力尚未定义，不默认赋予。先天一气维持与终结规则独立于后天流转。

此前六项地方特征仍有用，但储存、释放等参数应尽可能从材料与生命性质导出，不能为拟合某种生态外观任意指定。

举例推导：持续加工且结合强、释放慢，会使一定容量内的积累偏向物质内部；加工后易释放而空间流出较弱，会使环境可用量上升；若随后被生命吸收，灵气可能更多分布到生命体而非继续提高游离浓度。具体稳态或变化速度取决于所有通量与容量，不由单一系数保证。

下一步应逐项定义这些维度的意义、相互作用和最小参数，再决定是否采用此前建议的池、边、时间步实现。不以复现预设生态形态来倒推规则。

## 8. 第二轮问卷后的植物建模约束【用户已确定】

- 格子代表植物种群，个体生死更替；环境稳定时种群可以持续存在，数量的均衡随条件改变。不采用整格单体到寿命即清空。
- 少量植物功能类型需要生态特性，不只有灵气生产和消耗参数。
- 加工、吸收、释放能力独立数值化，允许双强、单强与中间程度，不强制互斥角色。
- 邻格种子扩散与条件适合后萌发；竞争环境灵气、空间和光照。
- 温度和水分首版是当地条件，不另建耗水养分循环；环境全年固定，但可人工编辑。
- 具体种群方程、同格共存、种子库和特殊单体仍待决定；此前年龄组及特殊灵树单体表示为实现建议。

## 9. 第三轮问卷后的约束【用户已确定】

每格最多一种树与一种草，不能仅在渲染时隐藏其他已建立种群。生态由相邻格子组合形成。植物包含全部已列生态特性，显示整数株数；内部生物量及库存仍须一致记账。

允许局部灭绝、有限寿命种子库及邻格种源恢复。普通植物按种群，极少数古灵树按个体记录年龄、后天积累和死亡；个体在单一树种限制下的计数与占位方式待确认。不得为实现方便取消种群更替或全格同时寿终。

## 10. 第四轮新增约束与模型修正

同层新种只在既有种群衰退且足够少时建立；古树占用该格同一种树的名额与株数，内部从普通种群独立记录。

古树成长可来自高效天道加工，也可来自对当地地道供给的直接吸收。灵植身份不强制要求天道加工系数大于零；普通植物天道加工为零的规则仍成立。用户新增恶劣高产环境中适配植物成长并改变地表的场景。

第一版未分属性不意味着来源不分。建议区分本格地下取用和环境取用，避免把仅有地表浓度的模型误认为能表达所有直接吸收场景。根系接触参数、地表改变方式和古树成长阈值均待细化。

## 11. 地表小环境反馈【用户已确定方向】

原型不再把实际温度和水分固定为地理常量。基础气候、地形、岩层与地热背景保持固定，实际地表条件允许因植被逐渐改变。植物适配读取实际地表条件，地质输入依然读取对应背景和地质状态，不自动因遮阴消除地下产灵来源。

新增动态状态为地表温度、水分（光照已有遮阴关系）；植物覆盖与冠层等决定局部反馈，具体函数、影响范围、限幅和变化时间尚未确定。保湿不是创建水分，降温不是无限抵消地热，二者的具体约束为待设计项。仍不模拟动物搬运，不加入灵气属性分类。
