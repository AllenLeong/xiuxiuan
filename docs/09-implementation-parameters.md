# 当前实现选择与待验证项

版本 0.2.0，2026-09-16。可调工程模型，不是最终世界参数。

- 时间步 0.25 年；256×256 标准，32×32 受控实验；格长尚未换算公里。
- 外边缘封闭、地表与地下邻接交换；州域按地形通达代价分区，计算灵气时不读取州 ID。
- 接收、加工吞吐、转化比例、容量、传导、释放分别保存。未接收或未加工的天道输入不计作已进入库存；根据新增设定，地表游离库以明确的宇宙逸散项输出。
- 0.1 曾在几乎每格持续较强产灵、单向释放地下库存，并按植物整个库存计算释放，造成地表大面积积累。0.2 降低低生产岩层供给、使地下释放随地表浓度反馈，植物释放改为新取得灵气的一部分加接近满载的少量释放。
- 地表平衡势参数暂按背景水分与地热求得，用于地下到地表释放驱动力，不是删除超过阈值的灵气；余量继续留地下或结合。
- 灵植积累阶段从 0 开始，不设六阶内容上限：适配且库存达当前承载 70%，持续 8×(当前阶段+1) 年可进一阶。承载乘 2，取用能力乘 1.4；不直接增加库存。尚需校准，与普通植物变灵植不同。
- 种群使用 8 个出生批次近似连续年龄分布，显示整数总株数，避免平均寿命导致整格同步死亡。古树为种群之外单独跟踪、但计入树层总数的一个个体；质量阶段目前按该格同种群代表值记录，古树独立质量阶段仍需进一步细化。
- 种子银行按物种记录有效数量和存留时间，不模拟动物。新生后天积累为零；先天一气按生命建立赋予。种子不单独计后天库存，是当前明确的简化。
- 最多一种草和树；换种残株自然终结，后天库存进入遗骸并记录。
- 树冠遮阴和水分留存逐步改变实际地表温湿度；背景地热不消失，保湿有背景供水约束。
- 事件保留最近 2000 条、编辑详细记录最近 500 次。界面显示截断，不假称完整几百年历史；正式验收还需补全可导出汇总证据。
- Canvas 二维绘制为首个可查看版本的实现选择；后台模拟与绘制分离，是否进一步使用 WebGL 依据测量，不宣称已达到全部图形性能要求。

## 尚未完成正式验收

当前规则测试只覆盖有限断言。11 场景处于校准阶段；旧版 500 年数据已标为 superseded，不能证明新版通过。浏览器长时稳定性、跨浏览器和完整用户体验尚未验收。

### 宇宙逸散（用户新增自然规则）

每步先完成吸收、结合与释放，再对剩余地表游离灵气计算 `逸散量 = air × (1 - exp(-escapeRate × dt))`。暂定 `escapeRate = 0.06 / 年`，孤立游离库半衰期约 11.55 年，后续按体验校准；不与地图格数绑定。地下及结合库存不直接扣减。

全局核算：期末 = 期初 + 外部加工输入 + 人工净输入 - 宇宙逸散。各格另计相邻流入流出。存档保留累计逸散，旧版同结构存档补零历史逸散并从载入后采用新规则。原场景校准结果需按新规则重跑，不继承旧结果为通过证据。

### 浓度驱动的吸收与分层收支

- 地表实际吸收 = `min(可用地表库存, 植物剩余承载, 吸收系数 × 生物量 × 时间步 × 适配 × 地表浓度 / max(1, 基础灵气需求))`。这使富集环境增加取用速度，贫乏环境降低实际取用；不会穿透来源和承载限制。
- 树先、草后取用，后者读取已扣减的库存；相邻格通过保守传输影响竞争。未来若需要同层多物种竞争，必须另行扩展数据模型。
- 质变仍需充足实际积累与持续时间；去除六阶硬上限，仅在翻倍会超出数值表示时停止，避免无穷库存。阶段使用 Uint16，旧存档阶段数据可扩展载入。暂定质变速度和倍率仍需持续评估。
- 加工、地下吸收、地表吸收和释放各有草层／树层收支，汇总等于格子收支；检查面板显示各层实际取用，防止把全格吸收误称为某棵树的贡献。
- `maturation=0` 为对照开关，只关闭质变；正式自然模式默认 1。
- 零地质加工效率是有效情况，不扣除 `0/0`，灵植仍可加工尚未被地质利用的天道输入。

### 大陆地形与自然图颜色

`src/terrain.js` 先生成带低频扰动的大陆轮廓、海湾与半岛、连续主山系与支脉，再按地势计算无环下游与汇水量。细小闭合低洼在生成时填至溢流水位，避免河流逆坡。河道影响背景水分；地理在运行中仍固定。州域从适宜陆地起点按山地、河流通达成本划分，不在海上画州界参考线。

背景温度 = 气候中心 + (南北位置 - 0.5) × 南北温差 - 海拔指数 × 22 + 坡向日照项 + 地热。默认南北温差 32°C，可在生成面板调整 0—80°C；不是一年四季温差。

自然图颜色由背景岩土、实际温湿、草树生物量覆盖混合。矿物仅按裸岩暴露近似影响地表色，不用地下储量染满地表。寒冷湿润区域呈霜雪色只是当前环境的绘制表达，首版不新增雪水储量模型。山形符号是海拔与山势的视觉表达，不额外生成资源。

地形标注遵循最新要求：允许“形容词＋地形”，不恢复州名或地点专名；由实际山地、平原、海域连通片生成，控制数量与碰撞。

### 湖泊、雨影与格子摘要

- 生成阶段保存地势填洼前后的差为 `lakeDepth`（海拔指数单位，尚未换算米）。深度超过 0.012 作为湖面；水系仍沿溢流方向流出，首版不实现动态水量收支。陆生植物不能在湖面萌发生长。旧存档没有该字段时补零，保留旧地图。
- 湖泊和河流提高近邻背景水分；默认西侧来湿的简化雨影由上风山体相对高度产生，背风侧水分降低。它是可解释的生成条件，不模拟逐日风雨。
- 侧栏摘要含年份、坐标、地形、冷热干湿、实际草树群落、最近一步总量方向、地表观测等级、灵植结构阶段。它是确定性状态摘要，不用 AI 推断历史。
- 地表观测分级暂定：0 级贫灵 [0,1)、1 级微灵 [1,4)、2 级灵润 [4,12)、3 级富灵 [12,35)、4 级高度富集 [35,∞)，单位为灵气单位／格。固定分级用于观察，不定义地区是否为灵地，不代表地下储量、植物积累或修士境界。
- “接近平衡”只指最近一步总量差在数值容差内；不宣称整个生态长期稳定。人工编辑使用独立时间窗口。

### 地形层级与局部特征

主地形按相对海拔、近邻起伏及远邻包围关系区分平原、丘陵、高原、盆地、山地、河谷、峡谷、海岸与水域。高原有生成阶段的抬升台面与陡缘；盆地必须表现为周围较高的区域，不等同于湖泊。

局部特征可叠加：河漫滩、三角洲、冲积扇、山谷、山口／鞍部、山麓、台地、洼地、悬崖／陡坡。`src/landforms.js` 给出判断条件与原因；河漫滩、三角洲、冲积扇目前是基于地形、水系与汇水量的判读，不宣称已经模拟季节洪水或泥沙沉积。悬崖与陡坡是格尺度相对坡势分类，未把海拔指数当成米或角度。

湖岛由湖盆中的自然凸起形成，并在汇流生成后按陆地连通片是否完全被淡水包围识别；接海或连着大陆的陆地不算湖岛。旧存档没有湖岛字段时默认没有已识别湖岛。

地形覆盖检查：256×256、种子「青野-001」、气候 24、雨量 0.5 的初始地图，已检出湖岛、河漫滩、三角洲、冲积扇、山谷、峡谷、山口、鞍部、山麓、台地、洼地、悬崖和陡坡，以及盆地、丘陵、高原、平原。逐类数量与可点击示例坐标记录在 `evidence/landform-coverage.json`。局部特征允许重叠，不把计数相加当成地图总面积；这只是生成与分类覆盖证据，不代表美术可辨识性已经验收。

格子摘要显示“主地形＋局部特征”，例如丘陵＋山麓；悬停局部特征可看判断依据。地表观测级与灵植阶段仍独立，不由地形标签直接赋予。

存档兼容：植物分层收支允许并归零绝对值不超过 1e-9 的负浮点尾差，明显负流量仍拒绝；生成阶段剩余天道预算也在扣除后夹至非负，避免继续产生负尾差。

### 定年推演与事件依据

“推演…”按当前年份加指定年数，在同一后台内核中推进；年数必须是当前步长的整数倍，单次上限 10000 年。到目标年份立即停止，不多跑一步。暂停、单步、编辑或载入会取消目标；继续普通运行不暗中恢复旧目标。

事件补充前后状态：建立保留原层与新层的数量和库存，自然死亡记录本步数量差、寿命到期数、适配／健康／过量风险与转入遗骸量；矿化起始记录地下扣减和矿物新增；人工干预保存精简且不递归嵌套历史的前后事实。自然事件的时间戳是触发步起点，其条件与变化发生于该步长内；人工干预位于已完成步的边界。格子收支中的“事件依据”可展开原始数据，缺失的旧记录不补造。

### 灵气流向图层

按用户最新要求，图层显示输送路线与库存富集位置。地下／地表各记录向东、向南两组带符号边流量，在实际源库存与容量限幅后记录；正数朝东／南，负数朝西／北。格子收支保留这些原始边数据以便核对。

路线算法从当步非零边流量的前 15% 中选主要流量段，沿有实际正向输送的相邻边向下游追踪，延续门槛为起始门槛的四分之一。至少连续三条边才显示为路线；相邻两格范围内的重复路线稀疏显示，每类最多 80 条。曲线只平滑连通路线的显示，不创造跨格连接。金线为地下、青线为地表，箭头表示方向，线宽固定按 0—10 单位／边／步的对数尺度。路线筛选为相对强弱，因此不同年份路线数量不直接代表总输送增长。

富集圈候选为地表库存至少 12，或地下＋矿物＋植物库存至少 600 的陆地格；按强弱稀疏保留最多 18 处以便观察。青圈表示达到地表门槛，金圈表示储存富集。这是可视化阈值，不定义游戏世界的灵地等级，也不保证这些地点正持续汇流。图层显示本步输送与当前库存，不能仅凭一帧认定永久灵脉。

初始世界与不含边流量的旧档提示尚无输送记录；完成一步后显示实际路线。四组数组随存档保存，并以 edgeFlowStep 标记对应步次。切图层不触发推演。人工编辑以后仍显示最近完成模拟步的路线，下一步才重新计算。

### 地表方向通达性（第一步实现）

新增 surfaceNorth/South/West/East，范围 0—1。地形生成时，每对相邻格按相对高差与两侧岩土粗糙度共同生成同一边的双侧通达性：`exp(-abs(高差) * 格网边长 * 0.75) * (1 - 平均岩性 * 0.55)`，内部连接下限 0.015，地图外边缘为 0。该映射是暂定地理工程参数，不意味着灵气因重力向低处流。生成后的结构不随每步库存变化。

实际地表交换率为可用量差 × 两侧相对面通达性的较小值 × surfaceDiffusion × dt，再受来源与接收余量限制。两侧共享边流量，入口与出口独立；关闭目的地出口会导致更多留存与回压，不会删除输入或复制分流。支持在编辑中单独调整四向通达性。缺少这些字段的旧档以全 1 迁移，保留旧交换语义；新地形结构需新生成地图。

本轮尚未增加地表可用容积或独立载体容量；土壤结合仍使用原有水分相关容量。这些是 11 中剩余工作，不因方向通达性完成而视作全部输送机制完成。方向隔离、目的地留存、非均匀分流与存档稳定性由 surface-transport.test.mjs 覆盖。

### 目的地容纳与岩土结合（独立化）

新增四个每格字段：airCapacity（地表游离池上限）、soilCapacity（岩土结合池上限）、soilBindRate（每年结合系数）、soilReleaseRate（每年释放系数）。它们与库存分开，容量扩大不填充库存。新地图工程初值依次为 `500 + 背景水分*500`、`5 + 背景水分*25 + 岩性*20`、`0.004 + 岩性*0.012`、`0.005 + (1-岩性)*0.02`。这是可调整的载体差异参数，不表示已定义物理体积或气压；现阶段地表横向驱动力仍使用同尺度可用量差。

岩土结合受速率及剩余结合容量共同限制；释放受原有库存、速率及地表剩余容量共同限制。地下释放、分解、植物释放和邻格流入均使用目的地的 airCapacity。无法转移的部分留在源载体，不消失。独立方向通达性决定是否继续流向邻格。

四项可在格子详情查看与编辑。容量编辑下限为当前对应库存（地表容量同时至少 1），过小值原子拒绝；不偷偷删除已有资源。旧档缺字段时，地表上限取 500、结合／释放速率取旧系数 0.008／0.015、结合容量由载入时水分推导且不小于已存量。迁移后容量为固定载体参数，不再随水分即时变动，这一差异明确属于新规则。

验证：retention.test.mjs 检查容量与结合速率各自作用、满载时释放限速、容量编辑不生成库存、无效容量拒绝。孤立逸散对照显式关闭结合与释放，不再用干燥条件间接隔离。

## 当前聚气与片区实现（2026-09-16）

以下覆盖早期按库存差传输的描述；植物从所在格取用仍可受当地浓度影响，两者不能混为一谈。

| 参数／状态 | 当前含义 | 约束 |
| --- | --- | --- |
| groundGatherRate | 地下地理聚气强度指数 | 非负；与地下充盈比例共同决定未满足需求 |
| gatherRate | 地表地理聚气强度指数 | 非负；零值空地不凭空吸引 |
| gatherLimit | 地表地理聚气饱和阈值，灵气单位／格 | 正值；达到后当地地理聚气贡献为零，不等同物理承载上限 |
| airCapacity | 地表物理容纳上限，灵气单位／格 | 所有入流共用剩余空间 |
| sourceMean / gatherMean / throughputMean | 生产、正净流入、过境量的三年指数均值 | 单位／格／年；未测历史不补造 |

吸引强度把未满足的地理聚气能力与适配植物取用能力合成为无量纲工程指数（当前归一化参考取1灵气单位／年）。最大有效路径每条边乘 `0.82 × 通达性`，以优先队列求解；不按海拔或库存梯度选方向。实际相邻转移为 `源库存 × (1-exp(-吸引强度差 × 通达性 × 传输系数 × 步长))`，再受每边源库存八分之一、接收空间八分之一限幅。四邻从同一步起点计算，转移后统一入账，不直接把远处库存交给目的地。

本步顺序：清账 → 古树冠层效应和聚气场 → 邻边交换 → 地质加工／出露／矿化／遗骸与土壤 → 环境松弛 → 树、草分别加工取用释放／生长质变／生死繁殖 → 游离逸散 → 总账 → 滚动观察／年度片区。古树边际牵引计算采用本步输送时的状态与实际边流。区域是观察结果，不反馈赋予灵地能力。

地形分类固定缓存；动态片区按模拟年更新。未变化的区域快照不重复传给主线程。古树影响局部重算与完整去树重算的等价测试见 `tests/ancient-influence.test.mjs`。片区门槛与显示规则见12；本节不把工程参数宣布为最终世界规律。
