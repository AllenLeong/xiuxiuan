# 灵气输送与通道逻辑

状态：按用户关于洋流、稳定通道和灵树吸收的补充整理。下列区分作为实现修正依据；势函数、时间尺度和具体系数仍需验证，不以已有画面证明规则成立。

## 1. 三层含义

- **传导结构**：岩层、裂隙、介质连接及地形决定哪里容易交换、哪里阻隔。自然地理固定时结构保持，不随每步库存重新生成。
- **实际流场**：各地输入、可用灵气、储存与植物吸收共同决定每条连接当前的方向和流量。它可以在固定结构上增强、衰弱或局部反向。
- **输送通道**：在传导结构上长期形成的连续、显著净输送带，是实际流场的稳定表现。地质轴线只能表示潜在通路，不能直接当成正在输送的灵脉。

“像洋流”指导连续流线的表现和可观察的长期结构，不自动引入惯性、风、旋涡、统一流速等尚未设定的规则。

## 2. 强吸收灵树如何从八方聚灵

1. 灵树按能力、适配与剩余承载，从所在介质取用真实可用量并存入自身。
2. 取用降低当地可用灵气或有效驱动力；连接地区仍有较高驱动力，便补入。
3. 邻近地区又获得更远地区补入，影响通过连接逐段传播。不能跨过中间格直接向全图扣库存。
4. 条件近似对称时可形成四周向内的流场；阻隔、供给差异与其他吸收者会令它偏向几条主要路径。
5. 中途植物从本地可用量取用并储存，截留部分到达的灵气。树得到的是经过沿途竞争后仍然到达的部分。

沿途植物可能因供应增加受益，也可能因为灵树把当地可用量压得更低而衰退；结果由到达量、停留量与竞争强弱决定，不写成固定增益。

## 3. 流量与平衡

每个位置分别记录输入、邻接进出、吸收／释放、储存变化与宇宙逸散。内部吸收表示进入植物，不表示消失。示意稳定收支可以是：外部输入 12，沿途植物储存 3 和 2，灵树储存 5，宇宙输出 2；不能让三个吸收者都取得最初的 12。

容量满且无法继续转化／成长时，实际吸收下降，向心驱动减弱。质变可以提高承载与吸收能力，必须有真实积累与时间条件。树死亡后，吸收停止、原有缺口逐渐消失，遗骸分解释放可能改变局部方向；不存在永久、无源的吸灵箭头。

## 4. 稳定性的边界

- 地质结构不变，潜在传导网络不变。
- 地理、输入和生态吸收格局均近似稳定，实际主流线应逐渐趋稳。
- 灵树成长、衰亡，群落变化或人工截流属于条件改变，即使山河不变也能调整实际流量和局部主流线。
- 不能为画面稳定而把流量锁死；也不能每步用不同随机抽样或排名让路线跳动。

## 5. 介质与驱动力（工程待验证）

地下传导与地表扩散分开记录，出口连接两者。地下用储存状态所对应的有效势差驱动，地表用可用浓度差驱动；灵树具有什么取用能力，就在哪一层制造缺口。势函数不能只因变量方便便等同库存，必须与容量和限速一致。

首版用相邻交换近似连续介质。绘制可以插值，但不能用视觉平滑来跨越不通的岩层，也不能把最近一条边的方向硬扩展成整条通道。长距离输送的传播时间、通道与基质的传导差异、逸散长度，都需要与地图尺度联合校准。

## 6. 下一轮必要验证

1. 同一固定地理，均匀输入、单株强吸收：观察局部向心补给，远处响应有延迟。
2. 相同起点关闭该树吸收：向心流应明显减弱，不只改箭头。
3. 沿途增加植物：逐段账目能说明截留和树实际所得；不预设沿途植物一定繁盛。
4. 关闭一条高传导连接：该路径输送下降，其他路径是否绕行由连接决定。
5. 树饱和或死亡：吸收下降、流场逐渐改变，遗骸释放有来源。
6. 固定源与吸收者长期运行：检查通道形状与流量趋稳；没有地理变化时不重新生成地质网络。

早期图层曾把地质轴线直接画成路线，再标注附近采样流量。这不能证明真实输送，已由下述实际流量追踪替换。四向离散交换与连续显示仍须区分；长期主通道稳定性待验证。

## 7. 地下释放后的横向输送（用户最新补充）

地下出口把灵气转入当地地表可用池，并不终结输送。此后去向包括当地生命吸收、当地载体结合／储存、经连接横向流出、游离部分向宇宙逸散。横向流动不能采用全图一致、四个方向等强的扩散条件。

必须区分三个决定因素：

- **驱动力**：相邻位置的有效可用状态差，决定当前输送倾向；灵树吸收可以持续制造局部缺口。
- **连接结构**：接收地与发送地相接面的通达性共同决定能否通过、通过多少。开放方向可以继续输送，阻隔方向弱流或不流。不以州界作阻隔。
- **目的地结构**：容纳与结合能力、植物取用、各方向出口决定到达后的留存和继续传递。入口强、出口弱可以逐步积累，直到回压抑制流入；入口和出口均强则可以是低库存的过流地带。

目的地不是流入后的简单“消失点”，也不能无条件复制收到的灵气向四周分发。所有流出共享同一可用池；上一步末状态或明确的同步更新规则决定本步请求，防止一次大时间步跨越任意距离。

首版待落实的数据：地表可用容积／承载、介质结合与释放能力、四个方向的通达性。边的通达性由两侧共同计算，不能因遍历顺序产生单向漏洞。地形、岩土、植被怎样映射到这些系数是工程规则，必须单独登记和测试；不能未经设定就把灵气当水、强制高处流向低处。

必要对照：相同输入下，分别放置低出口蓄积地、双向贯通过流地、多出口分流地与近乎封闭的阻隔地，比较库存、流量和逸散；修改一个方向的出口，验证仅相应路径的直接通达性改变。目的地吸收增强可以改变周边实际流场，但不得凭空改变地质连接。

早期实现只有全局统一的 `surfaceDiffusion` 系数，不满足结构化地表输送要求。当前它作为整体时间尺度系数，与各方向通达性共同作用；不能把它单独解释为全图均匀扩散。旧版本长期报告不作为新增规则已实现的证明。

### 实现进度补充

四向通达性已实现并有入口阻隔、出口留存、非均匀分流对照。地表游离池上限、岩土结合容量及结合／释放速率已独立，参数与迁移行为见 09。当前仍需验证标准地图上的通道长度、稳定性与实际汇流；上限不等于物理体积，目前尚未引入体积换算后的浓度势函数，不能宣称所有结构化输送问题已解决。

### 目的地结构的直观判读

以下是可能结果，不作为地形预设类型或强制演化目标：

| 到达处的条件 | 可能出现的结果 | 不能据此推断 |
| --- | --- | --- |
| 前后贯通，侧向难通过，结合较弱 | 主要沿连续带继续输送 | 流量大就一定是灵地 |
| 多方向开放，邻区可接收 | 向多路分流，比例由连接与邻区状态决定 | 必须向四周等量扩散 |
| 入口通畅，出口较弱，存在剩余储存能力 | 逐步留存，储满后流入受限或改道 | 永久无限积累 |
| 植物吸收强且尚有承载空间 | 植物积累，地表游离量可能保持较低 | 强吸收地表必然高浓度 |

目的地结构决定“能够怎样走、能留住多少”，还需结合源头供应、两侧可用状态和后续接收能力，才能决定“实际怎样走”。没有驱动力时，开放通路也不会自行产生输送；不能仅为了画出洋流形状而添加永久箭头。

## 8. 实际流线显示（2026-09-16）

地下与地表都从最近完成一步的有符号面流量追踪，不读取地质轴线来指定路线。格内沿东西／南北两个分量分别插值相对面的法向流量，以固定 0.2 格的短步积分；每段实际跨过的面都再次检查方向与非零流量。遇零流、逆向、边界、汇入终点或回环时停止。线条直接连接密集采样点，避免曲线平滑跨越屏障。

采样起点使用固定的二维低差异序列（基数 2／3），每层最多 512 条，不随每步排名重新挑选源头。重绘同一状态得到同一组路线；生态流量改变仍可让路线变化，不承诺山河固定就所有线永久不变。当前为最近一步流线，不是长期平均通道或灵气粒子旅行史。单条不足 2.5 格的路线省略，因此没有画线不证明没有短程交换；流线密度也不表示总流量。线宽按固定 0—10 标尺表达沿线插值流量的平均强弱。

`tests/flow-streamlines.test.mjs` 检查无流不画线、两层实际方向、地质轴线不影响路线、零流墙与角点阻隔、向心汇流终止。`evidence/flow-route-audit.json` 在普通种子青野-001、256²、10 年状态检查约 10.3 万段，0 次违背实际面流量的穿越；四象限均有路线。同一状态提取完全一致。该证据仅验证显示与当步数据的一致性，不能证明长期稳定、真实世界中的长距离运输，也不能替代浏览器视觉及帧率验收。

## 9. 固定条件下的输送稳定性与断路（受控验证）

`verification/stable-channels.js` 使用同一内核：16²、一个地质源、一个长寿命且未饱和的吸收者、两条明确相连的路径。生长、繁殖、环境反馈与矿化关闭以隔离输送机制；植物仍真实吸收、存储及凋落，不逐步删除资源来强制平衡。每一步逐格分池审计。

首次观察第 800—1000 年，库存与流量向量的相对变化为 0.026257，未通过事先设定的 1e-4 阈值；原始结果保留在 `evidence/stable-channels-initial.json`。源库此时仍从约 956 增至 980，固定加工能力尚未形成稳定释放量。未修改内核或放宽阈值，延长观察到第 2000／3000／4000 年：地表库存及全部地表面流量在这三个记录点一致，3000—4000 年相对变化为 0。植物内部库存和遗留物仍可变化，不把局部流场稳定说成全世界所有库存不变。

第 4000 年同档三分支各继续 200 年：

| 分支 | 直达边流量 | 绕行边流量 | 末端植物吸收 |
| --- | ---: | ---: | ---: |
| 不改变连接 | 0.139906 | 0.030926 | 0.055397 |
| 只关闭直达边 | 0 | 0.053135 | 0.009805 |
| 两条路径都关闭 | 0 | 0 | 约 1.78e-9 |

表中均为最后一步的灵气转移量，每步 0.25 年。断开后末端残存灵气按规则逐渐被吸收或逸散，所以不强求瞬间清零。全部分支逐步审计 0 违规。固定地表结构在未编辑阶段完全不变；打开的绕行路径原本存在，模拟没有为保持供给新建通道。

完整来源散列、七个时间点的数组、三分支与判定见 `evidence/stable-channels.json`。这个实验验证固定条件下可收敛、真实连接决定绕行；它不是普通大陆主通道长度、自然生态长期稳定性或浏览器流线效果的验收证据。

采样修正：旧的行优先索引 bit-reverse 排序虽覆盖四象限，却在路线预算截断后优先选中少数整列，造成纵向斑马纹。用户实际画面暴露此缺陷，已更换二维采样并增加列分布回归。流量守恒和跨面方向检查不足以保证视觉空间分布合理，两类验收须分别执行。
