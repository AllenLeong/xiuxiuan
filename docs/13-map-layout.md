# 地图布局修订

2026-09-17，依据用户提供的天下／青州双图参考。用户重点为布局，暂不扩展美术、城市或宗门。首版仍是一州及周边，采用参考图右侧的地理层级。

## 当前生成结构

- 大陆连续腹地向西、北和西南的观察窗外延续；观察窗边缘不等于大陆海岸，也不改变现有封闭模拟边界。
- 不规则东岸形成海湾、突出半岛，近海岛链独立于主大陆。
- 多条相连又有间断的山系，围合北部、中部、南部腹地；西北保留低起伏高原。
- 穿山河谷提供盆地到沿海的排水出口，河流继续由高程和汇水推导。局部闭合洼地形成湖泊，孤立岩峰可成为湖岛。
- 海拔、坡向、气候与地热继续参与温湿度；岩层与断裂跟随山系。没有按州名指定生态或灵气属性。

轮廓、山系、岛链为参数化宏观骨架，种子扰动位置和岸线；目前不宣称所有种子都有完全不同的大陆拓扑。后续应把这些骨架作为可配置布局模板。

## 检查与限制

浏览器实际检查默认256²第0年：可见连续大陆、多组山地、贯通河谷、东岸海湾和海岛。首轮因封闭山系出现过大湖泊，增加地形侵蚀出口后再次检查，保留局部湖而打开内陆腹地。

地形／存档／数值单测运行后记录在rules-test-output.txt。原whole-snapshot测试假设固定格树层为空，新地形改变初始植物，改为先用公开移除命令清空树层后建立测试古树；续跑逐字段断言不变。

本次改变新世界初始数据，旧世界存档仍保存原地形。旧五种子500年、场景、性能报告不证明新生成器完整长期验收，需重验；08整体目标保持未完成。


2026-09-17 用户修正：不需要大量海岛。移除六岛近海链，仅保留一处较小孤岛候选；东部山系收回大陆沿岸，以大陆、海湾和半岛为主。湖岛仍由内陆水系形成，不随海岛候选删除。新世界采用此布局，已有存档不改地形。


腹地比例修订：海岸收至东侧，三组长主山系与两条短支脉，两个更宽的内陆低地，以长河谷连接东岸出口。仍为256²，种子扰动骨架，不宣称实现完全随机大陆。


尺寸对比：新增512²与1024²生成／载入尺寸白名单和UI选项，默认256²。两种尺寸浏览器实际生成和全图绘制成功。Node同种子首步测量见size-512-smoke.json和size-1024-smoke.json：生成1.43／5.40秒，首步0.376／1.619秒，进程RSS约426MB／1.31GB；不是浏览器总内存或长期吞吐验收。布局目前按归一化坐标生成，增大格数提高分辨率与实体数，不自动增加新大陆或州域纵深。1024全图符号偏密，需后续显示细节等级优化。大图真实文件导出／恢复尚未验证，未宣称其完整验收通过。


山脉表现修订：不再每5格排列同款三角峰。按屏幕尺度聚合真实高地，缩略时每约22像素选取局部高峰，使用不对称山肩／侧峰、曲线山坡及阴面；放大增加可见峰群。仅改Canvas表现，不改变高度、通道或生态状态。256²实际截图已检查。


山峰大小与高原澄清：峰群大小和高度结合绝对海拔、局部相对高差；高地局部起伏小于0.023不绘制独立山峰，避免平坦高原铺三角峰。高原仍由地表底色与坡缘高差表现，地形分类和数据不受绘制影响。


高原可辨识修订：自然地图按实际plateau片区绘制连续台面、稀疏水平层理和坡缘明暗，使用缓存轮廓及范围，缩放不改变高原成员格。256²浏览器截图检查，错误日志为空；几何缓存／绘制时序测试通过。视觉效果仍需用户评价，不标完整U02通过。

### 固定山体与等高线（2026-09-17）

替代此前按屏幕缩放重新选峰的实现。峰群只按静态地形选取一次，位置、大小、轮廓均使用地图坐标；相机只整体缩放，不再取消缩放或重新挑选山峰。可见范围裁剪包含山顶至山脚，山脚在屏幕外不会导致山顶消失。

自然图的等高线按固定高度层进行 marching squares 插值，表示真实地形起伏；平坦高原不会仅因海拔高就被画成峰群。保留参考图的山峰表现，但山体身份不会随观察尺度改变。几何缓存避免每帧重新扫描地图。

回归验证覆盖跨缩放绘图完全一致、山脚在画面外时的山顶显示、平坦高原无峰。浏览器已观察全图和放大后的固定峰群，控制台无错误；用户视觉验收仍待评估。
