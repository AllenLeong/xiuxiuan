# 14 · 模拟维度、演化可见性与玩家空间

> 2026-09-19 更新：玩家空间现已确定为连续侧视世界，见 [17](./17-continuous-sideview-world.md)。本文早期俯视移动与飞行建议保留为历史，不再作为当前空间方案；底层维度梳理仍供生态实验参考。

2026-09-19。依据当前代码梳理；下文明确区分当前实现、用户提出的问题与建议。建议不因写入文档自动成为已确认设定。

## 一、当前问题

用户认可山体固定的方向，但认为当前框架未达到目的：维度过多且逻辑难懂；无法像观察物质流转一样观察演化；生态格网适合大地图计算，但玩家不应被迫走格子；修仙还需要表达飞行。

当前一格同时保存地下、地表、岩土、植物和遗骸库存，一格不是一个物件。普通草树按种群，古树单独跟踪。这是世界尺度的统计模拟，尚非逐株局部生态，也不是玩家实际行走空间。格长尚未定义，512/1024主要增加分辨率，尚未建立一致的公里与局部尺度换算。

## 二、不要把五个观察维度当成五套世界规则

五个片区入口：地形、温度、林区、古树作用、灵气特点。它们都是对底层状态的判读；其中地形主要固定，另外四项随状态更新。综合地域是多维足迹组合，也不是新的生产机制。

### 底层逻辑维度对照表

| 逻辑维度 | 定义与判断 | 当前演化 | 对其他项的影响与交互 | 首轮观察建议 |
|---|---|---|---|---|
| 地形与水系 | 高度、局部/区域起伏、坡向、湖深、河道；派生山地/丘陵/高原/盆地等 | 生成后固定；编辑部分环境参数不等于地貌演变 | 决定光照、温度、水分背景、通达性；地形标签不直接生产灵气 | 作为底图，默认不要求逐项读参数 |
| 岩性、裂隙、地热 | 当前是抽象岩性系数、裂隙系数、热背景；不是完整矿物种类 | 固定背景，允许局部干预 | 推导地质加工、储存、传导、出露、聚气等参数；地热影响温度与产能 | 点击来源时展开成因 |
| 实际温度、水分、光照 | 区分背景与实际；树冠遮阴影响林下光照 | 温湿逐步向背景加冠层作用的目标恢复 | 决定物种适配、生长、吸收与死亡；植被反过来降温、保湿 | 适生/不适生与变化原因优先；不是水量或热量守恒模型 |
| 外部输入与加工 | 天道预算 → 地质加工或灵植加工；普通植物不加工 | 每步按输入、加工吞吐、适配与剩余容量形成新增灵气 | 地质输入进入地下；植物加工进入植物库存，后续释放才到地表 | 明确显示来源、每年新增量 |
| 地下库存与出露 | 地下可移动灵气；容量与当前库存独立 | 接收加工输入、横向输送、根系吸收、矿化、向地表释放 | 出露受速率、地下充盈、地表状态与接收空间限制 | 显示储量与出露量，不能混为生产量 |
| 地表游离库存 | 当地未被结合或吸收的灵气 | 出露、释放、分解、邻格输入；吸收、结合、输出、宇宙逸散 | 可暂时富集，但容量有限；供给、取用、输送、逸散共同决定状态 | 默认主观察对象，显示收支与趋势 |
| 聚气能力与通达 | 聚气效率、聚气上限、植物需求构成吸引；相邻通路限制传递 | 自身需求随剩余容量、适配与生物量变化；吸引沿有效通路衰减 | 方向依据吸引势，不依据海拔或浓度差；实际流量仍受源库存与目的地容量限幅 | 单独看吸引目的地与实际路线，不能把二者画成同一个量 |
| 岩土与矿物结合 | 岩土结合池和灵矿池独立，不等于地下游离池 | 岩土结合/释放；岩性>0.55、地下充盈>0.5持续条件累计>8年后矿化 | 从其他池扣除同量，不凭空生成；岩土可再释放，当前灵矿主要积累 | 展示存储去向；不宣称有完整风化/采矿生态 |
| 植物种群与竞争 | 每格最多一种树、一种草；数量、生物量、年龄批次、种子库 | 生长、繁殖、邻格种子扩散、死亡、衰退后换种 | 竞争空间、光照与灵气；当前树先草后吸收，非公平同时分配模型 | 单种观察，显示建立、扩张、衰退、退出 |
| 植物灵气能力与质变 | 加工、地表吸收、地下吸收、释放、承载独立连续参数 | 灵植充盈≥当前承载70%、健康>0.2持续8×(阶段+1)年可进阶；承载×2、取用能力×1.4 | 更多灵气先转入植体；进阶不新增灵气；满载抑制需求；普通植物不因浓度高自动变灵植 | 区分种群扩张、生物量增大和灵气阶段提高 |
| 古树个体与作用 | 古树身份、年龄、生物量、库存；计入该格同种树总数 | 生长、积累、寿命及环境死亡；当前与所在种群的质量阶段仍有耦合 | 牵引通过去除其贡献的本步对照识别；滋养通过额外冠层效应降温/保湿；二者不是同一范围 | 选择一树，分别观察取用和环境作用 |
| 遗骸与宇宙逸散 | 死亡/凋落后的后天灵气进遗骸；剩余游离气向宇宙逸散 | 遗骸缓慢分解回地表；逸散率当前0.06/年 | 回流不算新增；逸散是系统输出；先天一气不进入可回收后天库存 | 在收支图中给回流、永久输出明确去向 |

以上阈值和倍率是当前工程实现，不是最终世界公理。先天一气与寿命属于生命规则；目前不是可在后天灵气路线图上流转的物质。

### 片区的判读逻辑

| 片区入口 | 当前判读依据 | 是否自己推动演化 |
|---|---|---|
| 地形 | 海拔、起伏、包围关系、水系等分类后形成成规模连通片 | 否；底层地形参与计算，标签不参与 |
| 温度 | 冷≤5°C，热≥32°C；地热背景≥10另识别 | 否；实际温度参与植物适配 |
| 林区 | 树生物量与体型对应覆盖；建立覆盖≥0.35，既有片区退出门槛0.25；允许小孔隙 | 否；不是每格必有树，也不等于灵林 |
| 古树作用 | 牵引：实际边流及去树对照；滋养：相对其他冠层额外作用≥0.08；保留树来源 | 否；作用计算参与输送/温湿，区域只是足迹 |
| 灵气特点 | 三年平滑：生产≥0.3/格/年，净汇入≥0.15，通过量≥0.08 | 否；生产、聚气、通过是不同作用，不等于高库存 |

一般地形/冷热片区至少48格，林区24格，灵气片区12格，古树作用9格；动态片区持续5年才建立，消退保留不足5年。初始化片区历史未知，不伪造形成时间。通道允许狭长形状；其他片区有宽度条件。

**问题：这些门槛以格数计，尚不能直接当作物理面积。** 在格长和观察尺度确定前，不能认定不同分辨率下区域判断完全一致。

## 三、演化目前为什么不明显

1. 一格代表种群及多个库存，但地图只画代表符号，储量和生物量变化不一定改变符号。
2. 快进几百年只看终点；缺少同一位置的时间对照、阶段过程、来源与去向。
3. 从已有积累和植物开始，部分地区接近某种稳定状态；后续可能是种群周转，而非版图剧变。
4. 固定地理不应凭时间自行变化；动态应主要出现在灵气、植被、积累、质变和死亡上。
5. 如果受控干预也无法造成可预测差异，属于模型或参数问题，不能靠动画掩盖。

## 四、建议先用一类灵气贯穿所有载体

借鉴用户希望的“一个类型看得到流转”，不先把世界改成一格一物。当前一格多库存更适合世界生态，但应允许**一次只观察一个对象**。

首轮只追踪未分属性的后天灵气：

天道加工输入 → 地下 → 出露 → 地表 → 灵植 / 岩土

灵植 → 活体释放 / 凋落与死亡 → 遗骸 → 地表

地下 → 灵矿；地表 → 邻区 / 宇宙逸散

建议界面：

- 常规地图减少常驻维度；选“灵气”后选载体：地下、地表、植物、岩土、遗骸、灵矿。其他条件按需展开。
- 选一个源区或一株古树，显示实际输入、存入、流出、吸收、回流、逸散；箭头动画是实际边流的表达，不是模拟粒子。
- 保存起点对照和时间序列：库存、生物量、质量阶段、范围；显示“最近50年发生了什么”。
- “当前流经路线”与“特定来源最终去向”分开。后者需要新增来源标记/示踪库存；现有边流和去树对照不能证明每份灵气的来源。
- 提供无树/有树、不断流/断流的同种子分支实验。只改变一项，比较同年份结果。

首个观察场景建议锁定：一处普通谷地、一株加工强的灵树、有限外部供给。先能清楚观察它积累、释放、周边建立、竞争与自身死亡后的回流，再恢复完整大陆观察。

建议验收：看图即可找出源、通道、吸收者、存储与逸散；十年/百年前后有数值和范围证据；树更强不等于全地表无限升浓；关闭来源后各库存按各自速率衰退；内部流转守恒。

## 五、模拟格网与玩家空间建议

格网作为计算单元，不必成为移动单元。人物可用连续坐标行走，查询脚下所在格及邻格环境；格线只在观察/编辑时显示。粗格生态不能直接提供山石、房屋、悬崖等精细碰撞几何。

建议区分三个尺度：

1. 世界地图：看山系、州、森林、源区与通道，支持远距离旅行。
2. 地区观察：看生态格子和时间演化，允许研究与干预。
3. 玩家局部场景：连续移动，单株、建筑、地形细节和碰撞具有实际尺寸。

首轮不同时实现三套模拟。先确定格长、世界尺度和局部细节接口；未来局部场景的资源改变必须回写同一个世界库存，不能进场刷出另一份资源。局部细节生成、离开后的汇总与生命周期结算仍待设计；避免粗细模拟重复生长和重复库存。

## 六、飞行展示建议

先在俯视或斜俯视空间增加人物高度，不必立即制作全3D世界。

- 地面影子固定投影落点，人物有高度标记/垂直连接，区分飞行者与地上位置。
- 状态分步：步行、低空御器、高空赶路。低空仍读当地障碍高度，高空可以跨过部分障碍；高山不能仅因进入飞行状态就默认可穿越。
- 空间数据至少区分地面高度、障碍顶高、人物离地高度和绝对高度；离地高度随脚下地形变化。
- 落地要检验落点、坡势、障碍及进入权限；飞行不等于可以随处进入宗门。
- 大地图高空赶路展示连续轨迹、耗时与抵达位置；接近目标进入局部场景，避免粗格一跳一格。
- 首版只有地表灵气，没有高空灵气分层。不得默认飞到高处能照常吸收地表灵气；高空生态、天气、空战、阵法限制以后另设规则。

这只是表达方案。是否需要玩家局部场景、俯视/斜俯视、空战深度及升降操作尚未确认。

## 七、建议下一步

暂停新增生态属性和片区类别。先评审本文的底层逻辑，选一条可观察的灵气流转链，做小范围时间对照原型；大陆地图保留为背景。验证演化后再决定局部玩家场景与飞行表现。
