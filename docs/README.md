## 状态约定

- **已确定**：用户明确提出或确认的方向；本轮草案明确标注为确定的规则。
- **草案规则**：本轮提供的工作设定，可以作为讨论基线，但仍待整体定稿。
- **建议**：此前或本轮助手提出、尚未得到明确确认的机制。
- **待定**：存在缺口、冲突或多种可行解释，不得在实现时默认为已确定。
- **演示例子**：用于解释机制的地名、年份、数量和故事，不是固定世界事实。

本文档为当前对话的整理版，并非逐字聊天记录。后续修改应保留决策状态；没有确认的建议不能因写进文档就升级为设定。

## 当前工作顺序

世界起点与修仙基本规则 → 连续地理与资源过程 → 人物与组织行为 → 历史演化 → 玩家进入 → AI 表达。

以下为早期阶段记录；当前已进入生态实验与连续侧视可玩切片并行验证，入口见 17。

早期优先讨论无修仙法门介入的自然灵气生态与生命规则。活体夺取、延寿、施法、炼丹、阵法等留到后续法门阶段，不作为当前自然设定必须解决的问题。尚未实现模拟器，未确定参数、境界数值、州数量或具体世界地图。

## v0.2 决策记录

- 确认：先天一气依附于完整的生命联系；生命不可逆崩解时，剩余部分随之耗散，不成为可采集资源。
- 澄清范围：先完成自然状态的规则，再讨论修仙法门如何介入。
- 保留但延期：此前夺取、延寿和法门消耗的分析，不代表这些能力已经存在或被禁止。

## v0.3 决策记录【植物能力范围已被 v0.4 替代】

- 确认：植物可以自然吸收、加工天道之气，但效率低，需要时间积累。
- 修正：不再把这一能力限定为少数珍稀灵草的特例；生态既有植物带来的外部输入，也有内部流转与留存。
- 保留待定：动物和人类的直接吸收能力、植物加工所得的命名及具体效率。

## v0.4 决策记录

- 确认：灵植／灵草才可以吸收、加工天道之气，普通植物不可以，与普通人无法聚气相对应。
- 确认：灵气聚集的地方会有灵草；另有天生高效灵植，可通过加工天道之气使当地逐渐富集灵气。
- 替代：v0.3 中所有植物均能低效加工的表述不再适用，也不将所有灵草效率统一规定为低。
- 待定：普通植物是否及如何转变为灵草；加工产物进入环境的路径后于 v0.5 明确。

## v0.5 决策记录

- 确认：灵植在活着、生长时，缓慢释放部分加工后的灵气到周围环境，同时可以积累自身。
- 衔接：活体释放、凋落分解、摄食传播共同构成灵植影响环境的自然路径；流转对象为后天灵气。
- 待定：释放比例、速率与生长阶段的关系；不默认需要储满才释放。

## v0.6 决策记录

- 确认：保留生态形态作为结果，去掉动物跨地点搬运灵气的机制。v0.5 摄食传播中的跨地点部分被此条替代。
- 当前方向：从原子状态和局部规则推演生态，不按生态标签生成结果。
- 新增第五份模拟建议文档；其中数据结构与计算规则仍为建议。

## 2026-09-16 设计方向澄清

- 生态形态只是可能性参考，不是模拟目的；在相应条件下，由底层维度与交互规则自然产生。
- 先讨论天道接收、物质加工、承载与亲和、空间通达、加工性质、生命适配和生命周期等因果维度（具体划分为建议），再选择库存和时间步等实现。

## 第四轮地图问卷已记录

同层衰退后替换、古树计入唯一树种和总株数；新增恶劣高产环境中适配植物成长为古树并改变地表的情境。古树不要求具备天道加工能力，具体成长和地表改造机制待细化。

## 第五轮地图问卷已记录

确认植被可以逐渐改变局部温度、水分；背景气候和地热固定，实际地表小环境动态变化。具体反馈函数与强度仍待设计。
