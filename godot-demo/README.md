# 层峦山域 · Godot 可玩场景

以网页版 `/sideview/` 的「层峦山域」为布局基准。直接从 `sideview/mountain-scene.js` 导出七块山地、谷地、四条桥路与五条石阶的坐标，保留角色近景尺度。参考图用于青绿设色、细墨线、树木与建筑风格。

## 运行

使用 Godot 导入本目录的 `project.godot`，按 F5 运行；本项目以 Godot 4.7.2 验证。引擎不包含在仓库或下载包中。macOS 安装 Godot 到应用程序目录后，也可双击 `启动场景.command`；启动器同时支持 PATH 中的 `godot` / `godot4`。默认从山腰院落开始，近景跟随人物。

- A/D、左右箭头：行走；空格：跳跃。
- W/S、上下箭头：沿贴崖石阶上下；F：御器开关，飞行时四向移动。
- V：切换全景和跟随近景。
- H：通路辅助线；C：实际碰撞查询网格。
- E：附近地点说明、恢复气息。进入洞穴不需要按 E。
- R：回到山腰院落；Esc：暂停/继续。

## 地形与洞穴

本版已停止使用整张山水画作为可玩地图。七处山体是独立 Polygon2D 地形，具有世界坐标固定的岩面纹理，树木和建筑分别摆在台地上。高低台地通过原版桥路和石阶连接。

三个洞口为台地上的真实开口，向下接入同一山体中的洞道。人物直接行走进入、原路走出；镜头继续跟随人物，没有洞内场景切换或传送。洞壁、洞顶和地基参与步行/飞行共用的多边形碰撞查询；扫掠步长最多 3 单位。洞穴以局部剖面展示内部空间。

沿用网页版的层叠表达：低处台地表示重叠高山前侧的外露道路，其上方有明确通行净空；山体深处保留实体。仍是 2D 侧视抽象，不是完整三维山体。远景山峰只用于背景。地形暂不支持自由挖掘。

## 文件

- `assets/layered-world.json`：网页版直接导出的地形和原洞口位置。
- `scripts/main.gd`：地形生成、洞穴空腔、统一碰撞、移动、镜头、交互和存档。
- `scripts/traveler.gd`：角色绘制。
- `assets/ink-atlas.png`：参考画风新生成的独立树木、建筑、植被图集。
- `assets/ink-rock.png`：新生成的岩面材质。
- `assets/qinglan-world.png`：早期整幅底画试作，仅保留，不再用于当前场景。
- `evidence/follow.png`、`overview.png`、`cave.png`：当前 Godot 实际运行截图。

保存位置为 Godot `user://layered-world-v2.json`。独立于浏览器版存档，不改动浏览器版文件。后台经济、战斗和世界生态尚未迁入，本版重点验证地形与通行。

## 检查

在本目录运行：

```sh
godot --headless --editor --path . --import
godot --headless --path . -- --test
godot --path . -- --capture
```

已检查：原版地形锚点、七山体及五条石阶数量、行走、跳跃落地、洞口连续进入/退出、五条石阶双向通行、洞顶阻挡御器、气息耗尽。测试和截图模式不写玩家存档。检查结果见 `evidence/checks.txt`。
